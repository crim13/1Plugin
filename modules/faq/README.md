# FAQ Module

Native Divi 5 module for the existing 1Plugin FAQ content.

The module renders `OnePlugin_Light_FAQ` posts and keeps visual styling in native Divi 5 controls:

- FAQ groups, item limit, columns, rows, order by date/order/random, schema output, open first, accordion behavior
- Item, Question, Answer spacing/background/border/shadow/text controls
- Divi icon picker for open/close icons
- Icon color and size controls

Admin activation setting: `module_faq_enabled`.
