# 1Plugin

`1Plugin` is a WordPress plugin for websites built primarily with Divi. It centralizes company and website data, exposes it through shortcodes, adds useful front-end tools, includes native Divi 5 modules for menus and FAQs, and can be updated through GitHub Releases.

The current version in this repository is `2.9.72-dev`.

For a complete description of the existing implementation, see `DESCRIERE-PLUGIN.md`.

## Main Features

* `1Plugin` admin page for project identity, company details, social links, logo, favicon, and site title;
* shortcodes for company information, contact details, address, map, website, and social profiles;
* shortcode support in content and in the attributes of certain Divi modules;
* keyword/SEO fields for pages, with dedicated shortcodes;
* sticky mobile footer with up to three configurable actions;
* front-end options for images, masonry galleries, header, footer, Formidable Forms, and section-based active menu states;
* color palette saved in the admin area and exported as CSS variables;
* custom CSS, JavaScript, and PHP code for the `head`, `body`, and `footer`;
* FAQ system with a custom post type, groups, JSON import/export, quick add, and FAQPage schema;
* native Divi 5 modules for menus and FAQs;
* REST routes for status, settings, menus, menu preview, and FAQ preview;
* built-in GitHub updater integrated with WordPress’s native plugin update system.
